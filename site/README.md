# Product page

`index.html` is the Sahifa product page: one static HTML file, no build step, light and dark
themes, served by GitHub Pages from this folder (`.github/workflows/pages.yml`, on every push
to `main` that touches `site/`). `assets/` holds the favicon, logo and the social preview,
generated by `docs/assets/genlogo.py`.

Preview locally: `python3 -m http.server -d site`, then open http://localhost:8000.

The same page can move to the Sira Labs site (`Sira-Labs/siralabs.github.io`) as
`sahifa/index.html`, with a card on the organisation page, once that is wanted.
