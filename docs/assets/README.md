# Logo assets

The mark is a sheet, a *ṣaḥīfa*, with a folded corner and three ruled lines. Each line is a
record (a short key cell and a value cell), and the sheet is sealed at the lower right with a
round seal carrying the eight-pointed star of two squares (Rub el Hizb): a record whose
promises are written down and checked. All files are flat SVG; the wordmark is outlined into
paths, so it renders identically everywhere (GitHub included).

| File | Use |
|---|---|
| `logo-light.svg` | Mark + "Sahifa" + "صحيفة", ink text, for light backgrounds |
| `logo-dark.svg` | The same for dark backgrounds |
| `mark.svg`, `mark-dark.svg` | Mark only, light and dark |
| `icon.svg` | The mark on an ink tile with rounded corners, heavier strokes; favicons and avatars, reads at 16 px |
| `social-preview.svg`, `social-preview.png` | 1280×640 card for the repository's social preview (Settings → General → Social preview) and link previews |

Colours (the product palette, `docs/frontend/01-frontend-design.md`): ink `#141b2d`, paper
`#fbfcfd`, lapis `#2b4fb3`; on dark backgrounds `#e8ecf4`, `#151c2e`, `#93abff` on
`#0d1220`. Type: "Sahifa" in Bricolage Grotesque Bold (the Sira Labs display face), "صحيفة"
in Noto Kufi Arabic Bold, the tagline in Figtree Medium; all SIL Open Font Licence.

The files are generated by `genlogo.py`; geometry lives in the constants at the top of the
script on a 400×400 grid. Run it from the repository root:

```bash
uv run --with fonttools --with uharfbuzz python docs/assets/genlogo.py
```

It fetches the three fonts from the Fontsource packages on jsDelivr into
`~/.cache/sahifa-fonts`, shapes the Arabic with HarfBuzz, writes the SVGs, copies `icon.svg`
to `web/public/favicon.svg` and `site/assets/favicon.svg` and `mark.svg` to `logo.svg` there,
then renders `social-preview.png` and the raster icons `web/public/icon-180.png`,
`icon-192.png` and `icon-512.png` with headless Chromium (`SAHIFA_CHROMIUM`, `PATH`, or
Playwright's cache; `--no-png` skips the step).
